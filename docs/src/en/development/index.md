# Contribute to pVisor

Start from the component or workflow you want to change. Keep execution behavior, tests, and both documentation languages in sync.

1. [Set up the development environment](engineering.md).
2. [Run the examples](examples.md) for the affected workflow.
3. Read the relevant [implementation design](../design/index.md).
4. Run targeted tests, then the required repository checks.
5. Follow the [release procedure](releasing.md) when preparing a distribution.

The [roadmap](roadmap.md) separates current reliability work from future platform directions.
