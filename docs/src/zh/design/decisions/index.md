# 设计决策记录（ADR）

!!! warning "规划中"
    目前还没有 ADR。现有的设计约束见[设计原则](../principles.md)。

## 要回答的问题

重要的设计决策是怎么做出的：当时的背景、考虑过的选项、最终决定和后果是什么？

## 需求

- 建立 ADR 模板（背景、选项、决定、后果、状态）与编号约定（`NNNN-短标题.md`）；
- 回填已有的关键决策，例如：
    - 准入计划最高只到 `Planned`，强制力只来自执行器观察；
    - 网关（Gateway）与回放从核心闭包中分离为可选功能；
    - `--safe` 不选择执行器，做不到时拒绝启动而不是降级；
    - 语义规格的人工批准流程。

## 验收标准

- 至少回填 4 条 ADR，本页列出编号、标题与状态。
