# 0001：计划不能证明控制已经安装 {#adr-0001}

**状态：实现回填。** 记录现有合同，不据此推断维护者另行批准。

**背景。** 启动前可以判断请求的策略如何落实，但执行器可能因权限、平台或启动失败而没有安装控制。

**选项。** 可以让计划直接声明强制力，也可以等执行器返回实际观察。

**当前选择。** 准入计划最高到 `Planned`；实际强制力由执行器观察提供。Run Bundle 同时保留请求、计划与观察，见[证据设计](../../concepts/capabilities-and-evidence.md)。

**后果。** 自动化需要检查实际观察；平台适配器必须返回控制安装结果。任务结束或配置含有某个字段，都不能替代这份证据。
