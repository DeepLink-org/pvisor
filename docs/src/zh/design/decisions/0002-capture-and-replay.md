# 0002：捕获与回放有各自的数据职责 {#adr-0002}

**状态：实现回填。** 记录现有合同，不据此推断维护者另行批准。

**背景。** 运行一个任务、记录模型通信、恢复 Agent 原生上下文，需要的协议和依赖不同。

**选项。** 可以把所有协议放进执行核心，也可以通过独立组件交换明确的数据记录。

**当前选择。** Gateway 负责模型通信捕获与路由；Replay 使用原生 Agent 轨迹和工具重执行；执行核心维护 Run 生命周期与共享记录。Gateway 使用可选 feature，Replay 有独立 crate 与命令。见[回放设计](../replay.md)。

**后果。** 用户可以只使用执行与暂存。捕获日志与原生轨迹需要分别收集；新增 Agent 适配主要进入 Replay 的适配器边界。
