# 0003：safe 表达要求，执行器选择保持显式 {#adr-0003}

**状态：实现回填。** 记录现有合同，不据此推断维护者另行批准。

**背景。** 用户可能为了速度、Linux 用户空间或内核隔离选择不同执行器，同时希望文件与网络策略得到落实。

**选项。** safe 可以暗中改成某个执行器，也可以给所选执行器提出必须满足的要求。

**当前选择。** `--safe` 配置暂存、文件访问和环境等设置，不替用户选择执行器；无法满足所需控制时拒绝启动。具体网络路径见[网络策略](../../guides/policies/network.md)。

**后果。** 相同参数在不同机器上可能得到能力错误。解决方式是安装前置条件或显式选择满足要求的执行器；评审者从 Bundle 检查结果。
