# 论文、报告与演讲

pVisor 目前的公开技术材料由仓库设计与工程实验组成，可用于理解执行机制、选择实验对象，以及追溯结果对应的源码和运行环境。

## 已有工程材料 {#materials}

[回放保真度报告](../../benchmarks/replay-fidelity.md)测量固定版本轨迹格式的短前缀准备：校验历史边界、命令参数与工具观测，并记录从 CLI 启动到准备结束的耗时。`prepare-only` 不执行工具、不启动 Agent，也不修改工作区。这些结果可用于选择历史上下文输入；[回放设计](../replay.md)解释前缀准备、工具重执行与实时续跑的职责。

[RAM offload 附录](../offload/index.md#experiments)保留 2026-10-03 的存储／控制检查及压缩 backing 样本，可用于研究发布顺序、base/delta 继承和存储大小核算。记录分别列出通过的机制检查、进入 guest 前被阻断的测试，以及样本文件的逻辑大小和实际分配量。

已退役的[Controller/Worker 证据](../cluster-performance-analysis.md)提供冻结制品的历史测量。就绪探针描述 VM 就绪时间，历史查询测量描述保留记录的查询与热回放成本；完整任务批次保留自己的来源和统计口径。引用时按实验对象与批次分别取数。

具体未测范围：回放报告尚未测量真实模型续跑的一致率；offload 样本尚未测量净物理内存节省或多 VM 密度；当前 daemon 的性能与密度仍待独立实验。

## 新增公开产出的记录格式 {#record}

每条记录包含标题、作者或演讲者、发布日期、公开链接、材料类型、源码提交、Agent/模型版本、数据与复现入口，以及结论适用范围。论文列出发表场所与 DOI；预印本、工程报告和演讲分别标明类型。

若研究使用了尚未进入发布版的分支，写明分支提交和与发布版的差别。后续实现发生变化时保留原记录，追加新的验证结果或替代说明。

## 如何引用 {#citation}

引用某条性能结论时，带上报告日期、机器、执行器、任务和统计口径。引用设计时带上源码提交或发布版本。只在特定环境中观察到的效果，应保留该环境条件。

当前没有在此登记的正式论文、外部报告或演讲条目。贡献公开材料时，按上述字段提供可访问链接和复现信息。引用时区分设计提案、通过的机制测试与实测工作负载结果；实现保证以对应版本的文档与测试为准。
