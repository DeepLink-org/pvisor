# 用例：价值随规模展开

| 规模 | 读者 | 今天的痛点 | 用 pVisor 之后 | 级别 |
| --- | --- | --- | --- | --- |
| 一个人 · 一个 Agent | 开发者 | 要么守着批准弹窗，要么开全自动承担全部风险 | 放手跑完，事后像审 PR 一样挑着合入 | L1 |
| 一个人 · 多个 Agent | 开发者 | 多个 Agent 互相踩踏，审不过来 | 各自隔离、各自留证据，可批量审查 | L2 |
| 团队与平台 | CI、平台工程 | 不敢让 Agent 进入无人值守流水线 | 策略划边界、证据做审计，人只处理例外 | L3 |
| 研究与训练 | MLSys、Agentic RL | 大量 rollout 需要隔离、可复现、有记录 | 轨迹可记录、可分叉、可按前缀回放 | 方向 |

相关指南：[第一次运行](../start/first-run.md)、[在 CI 中运行 Agent（规划中）](../guides/ci.md)、[并行 Agent（规划中）](../guides/parallel-agents.md)、[RL rollout（规划中）](../guides/rl-rollouts.md)。
