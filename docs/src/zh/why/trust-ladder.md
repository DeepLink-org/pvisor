# 信任阶梯与规模轴

有两条轴：**人怎么介入**（信任轴）与**由什么承载**（规模轴）。

| 级别 | 人怎么介入（信任轴） | 承载（规模轴） | 状态 |
| --- | --- | --- | --- |
| L0 | 逐条批准命令 | 单个交互会话 | Agent 自带 |
| L1 | 事后审查每个改动 | 本机逐个 Job | pVisor 今天 |
| L2 | 策略与证据决定免审，人只抽查 | 本机多个 Job／一条流水线 | 下一步 |
| L3 | 事后审计，人只处理例外 | 集群化：跨节点调度、集中证据 | 方向 |

规模化路径：先把 L1 的三种性质做扎实，再让策略与证据承担免审判定（L2），最后交给 L3 的批量与集群执行。pVisor 是每次执行的语义层，不替代 Kubernetes、Ray 等调度器。
