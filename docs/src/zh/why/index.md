# 为什么是 pVisor

限制 Agent 自主性的不是算力，而是人的监督带宽：今天每一单位 Agent 工作，都要付出差不多同等的人工注意力。监督成本随执行量线性增长，自主性因此被人的注意力封顶。

要让监督与执行量脱钩，需要每次执行同时具备三种性质：

| 性质 | 含义 | 对你的作用 |
| --- | --- | --- |
| 有界 | 出错的影响范围事先可知 | 不必逐条事前批准 |
| 可逆 | 暂存文件可选择性合入、丢弃或分叉 | 失败成本低，敢于放手 |
| 可查 | 执行留下可核对的证据 | 审查可以抽样，直到交给机器 |

pVisor 是让每次 Agent 执行具备这三种性质的执行层——它是每次执行的语义层，不是调度器，也不是又一个沙箱。
