# 术语表

| 术语 | 含义 |
| --- | --- |
| Job | CLI 中一项持久的工作 |
| Run | Job 的内部记录；磁盘上仍是 `run-*` |
| Attempt | 一次执行 |
| Stage | 写时复制的暂存工作区 |
| apply / drop | 把暂存改动合入目标／丢弃 |
| Run Bundle | 结果、控制观察、产物与摘要的记录 |
| Capability | 一个能力维度的请求与实际控制 |
| Evidence | 实际安装的控制与观察，而非声明 |
