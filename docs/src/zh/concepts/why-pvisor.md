# 为什么使用 pVisor？

Agent、脚本或自动化命令可以完成有用的修改，也可能触及任务范围之外的文件或服务。只阅读命令输出，看不到完整的工作区结果，也无法确认执行时真正具备哪些控制。

PolicyVisor（pVisor）将声明的权限、实际控制和运行结果关联起来。启用 `--stage` 后，文件改动进入原项目之前还会经过审查，让你根据执行记录和工作区差异决定保留哪些内容。

如果你希望保留现有命令、检查工作区改动、分批接受结果，并留下本地执行记录，可以使用 pVisor。需要分析模型流量时，再开启捕获。

这个工作流不代替版本管理、备份、应用层授权或 Agent 框架。文件审查无法撤销远程副作用；应根据任务所需边界选择执行器和网络策略。
