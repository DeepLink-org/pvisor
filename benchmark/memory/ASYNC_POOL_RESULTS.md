# 异步物理页池：四 VM 的内存水位

## Motivation

四 VM 的静态堆负载仍显示物理页共享的空间收益，以及额外 CPU 和写后管理成本。
异步连接服务没有在这些单次观察中呈现较低的整体 CPU 水平。新的不可变文件
READ/mmap 路径没有被此负载触发，不能用本报告判断其性能收益。

相同随机内容在空闲末的整组计费内存为 physical 292.57 MiB、off 469.88 MiB，
名义 60 秒窗口的累计组 CPU 为 7.860 / 0.450 秒。全部改写为私有内容并再观察
30 秒后，physical 为 501.92 MiB，off 为 470.91 MiB。

## 实验设计

测量四 VM 完整资源组的计费内存、进程 PSS、CPU 和完整读回时间，作为指定工作集
的驻留成本。驻留成本包含 VM、物理页池及组内控制器，不是应用数据或扫描算法的
独立成本。内存和 CPU 越低，表示同一受限资源组为该负载保留的容量和执行成本越少。

这是 `B-MEMORY-SCALE` 的 engineering diagnostic，未替换用户 benchmark 正文。
Linux x86_64/KVM、Ryzen 7 9700X、宿主内核 `7.3.3-300.fc45.x86_64`，
使用当前源码重新构建的静态 musl release；源码身份为 `177c8a66` 加冻结的未提交
修改。guest 使用与此前 r6 相同字节的保留固件和相同静态 worker 源码，没有重建
或修改 guest kernel；它不是历史 q8/l4 文档固件的一致性证明。

每格四个 fresh VM，各 256 MiB / 一 vCPU / 64 MiB 数据，整组四核配额、
CPU 0–3、2 GiB、零 swap、256 tasks。三个内容条件分别运行 off、physical，
共六格，每格 N=1，无预热，按预定 seed 随机顺序运行。所有实例就绪后观察 60 秒，
再执行完整读回、25%/100% 私有写、peer 校验和额外 30 秒写后观察，最后独立退出
并校验存活实例。外部计费/PSS 观察者在组外 CPU 4–5，分别以约 50/500 ms 采样。
快照及曲线保留实际采集时刻，采集不是原子操作；扫描可在顺序启动期间发生。

KSM 始终保持 `run=0`，未改变宿主设置或停止无关进程。完整成功批次是
`.data/async-file-retest-20261115-r2/`，运行副本为仓库根 `.data/dm158/`；
它只复用 r1 新构建并逐项校验的制品，不复用 r1 的测量。r1 在第二格被其他工作区
的 cargo/nextest/rustc 干扰，43/196 个观察点受影响，保持不完整、不可用于性能结论。
两个批次没有拼接。

成功批次的 **348/348** 项数据与生命周期检查通过，24 个 VM 均正常退出，
**1,155** 个连续干扰观察点没有外部 VM/构建/测试记录，12 个 physical VM 日志
没有停发事件。六个资源组的清理检查及再次独立查询均通过。

计费内存包括已计入该 cgroup 的文件缓存与内核开销；PSS 包含池及验证映射，
但两者都不能独立代表整机净节约。CPU 秒包括 guest、池和组内控制/采集工作；
组外观察者不在其中。完整读回包括四 VM 的逐字节/摘要校验及控制往返，不是单次
内存访问延迟。N=1 不支持置信区间、尾延迟、正式版本退化判定或 2–3K 活跃 VM
密度结论。KSM、Firecracker、Docker、共享库/DAX 性能及运行中 daemon 故障未测。

## 实验数据和分析

### 空闲末水位与读回

四 VM 整组，N=1；内存为 `idle-60` 快照，CPU 为该空闲窗口累计值。

| 内容 | 模式 | 计费 MiB | PSS MiB | 组 CPU 秒 | 完整读回 ms |
|---|---|---:|---:|---:|---:|
| 重复内容 | off | 475.73 | 480.12 | 0.444 | 766.45 |
| 重复内容 | physical | 218.14 | 214.73 | 7.385 | 926.17 |
| 相同随机内容 | off | 469.88 | 480.09 | 0.450 | 754.56 |
| 相同随机内容 | physical | 292.57 | 294.59 | 7.860 | 1002.53 |
| 实例独有随机内容 | off | 469.88 | 480.13 | 0.443 | 781.88 |
| 实例独有随机内容 | physical | 457.07 | 471.99 | 4.013 | 751.38 |

physical 相对本批 off 的计费差值分别为 -257.59 / -177.31 / -12.81 MiB；
额外组 CPU 分别为 6.942 / 7.411 / 3.569 秒。这是本批观察差值，不是重复样本
的效应估计。独有堆以外仍有公共 guest 页面，不能将少量下降归为独有随机堆共享。
重复内容与相同随机内容的完整读回单次耗时更高；独有随机内容的较低单次读数
也不能被解释为稳定速度收益。

从各自 all-ready 水位持续下降 128 MiB 并保持到窗口末的采样区间，physical
重复内容为 0.624–0.707 秒，相同随机内容为 1.447–1.498 秒；独有随机内容和
三个 off 条件均未达到。这不是首次合并或完整收敛时间。

CPU 分项来自宿主进程计数器，按 clock tick 计数，采集时刻也不同，不能要求
与 cgroup 用量精确相加：

| physical 内容 | VM CPU 秒 | 池 CPU 秒 | 组内控制/采集 CPU 秒 |
|---|---:|---:|---:|
| 重复内容 | 3.77 | 0.46 | 3.14 |
| 相同随机内容 | 3.70 | 1.04 | 3.11 |
| 实例独有随机内容 | 2.70 | 0.76 | 0.55 |

因此相同随机内容的 7.860 秒不能全部称为扫描器成本。这里只分开观察了进程角色，
没有进一步隔离 VM 内的采样、hash、IPC 和映射，也没有扣除采集成本后构造新排名。

### 全量私有写后的水位

四 VM 均完成 100% 私有改写，再观察 30 秒；N=1，整组 MiB。

| 原始内容 | off 计费 | physical 计费 | physical − off | off PSS | physical PSS |
|---|---:|---:|---:|---:|---:|
| 重复内容 | 476.95 | 490.41 | +13.46 | 480.92 | 475.53 |
| 相同随机内容 | 470.91 | 501.92 | +31.02 | 480.88 | 491.99 |
| 实例独有随机内容 | 470.92 | 464.73 | -6.19 | 480.92 | 478.93 |

相同随机内容的业务共享收益在全量改写后消失，physical 仍多计费 31.02 MiB。
对应 kernel 为 31.60 / 5.54 MiB，slab 为 26.62 / 1.69 MiB（physical / off）；
**slab 是 kernel 子项，不能再加一次**。四 VM 的私有 pool VMA 从空闲末的
72,270 个变为写后 72,271 个，映射碎片没有随旧 payload 释放而消失。

同一条件的 pool memfd 已分配文件块从 72.62 MiB 降至 8.61 MiB，逻辑大小仍为
128 MiB。这是存储诊断而不是净内存；它不支持将写后额外水位全部归因为旧共享
payload 未释放。曲线显示释放有延迟，随后仍保留映射/内核及其他管理成本。
目前未隔离各项因果贡献，也不据 30 秒窗口判断长期泄漏。

### 与上轮的独立水位并列

以下仅为两个完整 N=1 批次的 physical 读数，不合并样本、不计算升级百分比。

| 内容 | 上轮 r6 计费 MiB | 当前计费 MiB | 上轮 PSS MiB | 当前 PSS MiB | 上轮组 CPU 秒 | 当前组 CPU 秒 |
|---|---:|---:|---:|---:|---:|---:|
| 重复内容 | 212.14 | 218.14 | 214.45 | 214.73 | 7.070 | 7.385 |
| 相同随机内容 | 292.25 | 292.57 | 294.89 | 294.59 | 7.412 | 7.860 |
| 实例独有随机内容 | 457.06 | 457.07 | 472.43 | 471.99 | 3.553 | 4.013 |

这些内存读数仍在相近量级，CPU 读数没有下降。重复内容的约 6 MiB 计费变化同时
出现在 off 控制：其 file 项由 0.23 变为 6.08 MiB，physical 的 file 项由
9.46 变为 15.06 MiB，而 physical PSS 只差约 0.28 MiB。不能把这 6 MiB
全部解释为 VM 私有内存或去重元数据增长；文件计费归属的具体来源尚未隔离。

异步服务针对连接数扩展性，这个四 VM 静态堆实验不能代替高连接数的吞吐/容量
验收。新的不可变文件路径需要独立的文件加载/mmap 对照来量化收益，不能拿本表
作为该路径无收益或有收益的证据。
