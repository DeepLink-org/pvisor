# 单写 stage 清理的性能验证

目录枚举和目录关闭回收的内部耗时有可重复的下降；常规查询和写打开没有可重复的稳定提升。不可变 lower 下创建目录在首批出现回退，独立复测未检出差异，仍不能排除回退风险。结果仅适用于宿主适配器内部路径，不能视为真实挂载或完整任务的加速比。

## 实验设计

基准 **B-FS-ENG**，工程 A/B。基线为清理前保存的源码，候选为清理后源码；只恢复 Core 的 `core.rs`、`service.rs`、`preimage_log.rs` 和宿主适配器 `fs.rs` 四份文件，其余源码相同。两组都包含此前的请求结果复用优化，本报告不重复归因此前收益。VM 的层索引改动不在被测差异内。

同机 Apple M4 / Mac16,12，10 个逻辑 CPU、24 GiB 内存，macOS 27.0.1 / Darwin 27.0.0，ARM64、APFS。两组分别用产品 release 配置构建：宿主适配器 opt-level=z、OverlayCore opt-level=3、thin LTO。无 CPU 亲和性或内存配额，宿主页缓存保持热状态。

Immutable/no-journal 和 Mutable/compact 两个条件独立统计。每批每条件 3 轮预热、30 轮随机配对，种子 20261020；每次新建 Core owner、upper、work 和日志。首批与独立复测各有 120 个正式运行和 12 个预热运行，不合并样本。独立复测因首批创建目录回退而追加，重复完整负载和相同随机顺序，保留首批全部结果。另有 4 个正确性预检和 4 个独立 profile 运行；profile 耗时不计入正式统计。

两份冻结源码插入相同的测试专用 probe 和 fuser ReplySender 导出，不改变产品源码或公开 API。使用实际 inode 查询、属性查询、写打开、创建回调、目录快照和 releasedir 回调；回复经序列化后检查成功。Rust Instant 计时排除 fixture、初始化、进程启动、最终验证和退出，不包含内核/FSKit、请求调度和完整 prepared-copy 队列。

输入为 2,944 个 4 KiB lower 文件。查询各 512 次（半数六级深目录），额外热属性查询为同样 512 路径重复 8 遍；写和每种创建各 128 次，写入 8 字节后关闭，无显式 upper fsync，compact 保留预映像持久化。目录原始条目数为 128/2048，各用 upper whiteout 隐藏四分之一，实际可见子项为 96/1536。每种宽度测一次快照，以及子 inode 未加载/已加载但 lookup 引用为 0 的两次关闭。子 inode 加载在关闭计时之外；已加载场景对应子项被 FORGET、仍由目录句柄固定的状态，不代表仍有 kernel lookup 引用时的关闭。

每个运行核验全部 lower 文件的字节和身份清单未变、upper 写入字节/类型/链接目标、compact 的 256 个写路径观察、work 清空、完整目录名称与 whiteout 过滤、关闭后的 inode/路径/对象映射回收、目录引用和无关旧节点存活。272 个运行均通过；错误样本和慢样本剔除数均为 0。运行前后检查构建/测试进程，未触发干扰门禁；边界检查不能排除短暂或其他后台负载。

各批独立按轮做 5,000 次配对 bootstrap（种子 4207）。下表为每批操作耗时，中位数单位 ms、每格 n=30，变化为候选相对基线，负值表示耗时下降。每批 28 个区间未做多重比较校正；区间包含 0 写“未检出差异”，不等于证明没有回退。分簇使用既有 distribution 规则；分簇单元格列各簇样本数和中位数，不报告整体 P50 或整体排名。绝对中位数差及其 95% 区间和完整精度统计保存在各批 derived-analysis.json / summary-reviewed.csv；不报告 P99 或稳定尾延迟结论。

## 解释与限制

2048 项目录快照在不可变配置中从首批 9.123 ms 降到 2.720 ms（-70.18%，95% CI [-73.29%, -65.30%]），复测从 9.820 ms 降到 2.961 ms（-69.85%，[-73.02%, -66.26%]）。可变配置两批分别下降 69.30% 和 71.00%。128 项目录也在两批、两个配置均检出下降，范围 59.51%～64.73%；这是四个独立点估计的范围，不是合并统计量。

2048 项目录关闭中，未加载子 inode 的不可变配置首批从 13.006 ms 降至 0.0368 ms，复测从 13.789 ms 降至 0.0431 ms；已加载、lookup=0 时分别从 21.834 ms 降至 0.5225 ms、23.980 ms 降至 0.6946 ms。绝对节省为单次目录关闭的数十毫秒，不能据此宣称整个文件系统或 Agent 快百倍。首批不可变配置的 128 项 lazy-close 候选分为 25/30 的 0.004583 ms 与 5/30 的 0.009667 ms，不用一个整体加速比概括它。

不可变配置的 LOOKUP 首批下降 4.21%，复测为 -1.54% 且区间跨 0，不能称为稳定查询收益。512 次 GETATTR 和 4096 次热 GETATTR 在两批、两个配置都未检出差异；缓存克隆减少并未在该负载中形成可重复的计时收益。

不可变配置创建目录首批从 11.994 ms 增至 13.040 ms（+8.72%，[+2.52%, +13.50%]）；复测从 12.532 ms 增至 13.133 ms（+4.79%，[-9.60%, +14.08%]）。首批不利证据保留，复测未能确认或排除这项回退。不能以“复测不显著”改写为“没有回归”；28 项未校正比较及宿主存储噪声也限制归因。

其余写打开和创建没有可重复的整体提升。复测 compact 基线的追加、截断、mkdir、FIFO 和 symlink 各检出分簇（低簇 23～25/30、高簇 5～7/30，具体数值见表），全部有效慢样本保留，不对这些单元格作整体排名。未将 raw summary 中忽略分簇的机械 bootstrap 数字作为结论；经过分布检查的 derived-analysis.json 显式留空这些排名字段。

whiteout 检查少 4,352 次，等于两个宽度目录各枚举两次的原始子项数；这与一次 upper 扫描过滤的实现一致。回收计数改为实际访问候选节点的路径及每批对象表，因而代表工作量减少，不是内存占用下降。metadata 调用没有减少，候选多两次；这些全程计数不足以定位创建目录首批计时回退的原因。

未测真实 FSKit/FUSE 传输、Linux、VM 层选择、legacy journal 的独立性能、冷磁盘、并发/多句柄固定、仍有 lookup 引用的关闭、read-only stage 观察者、硬链接或完整 Agent 任务。未重新尝试此前阻塞的 FSKit 挂载，未操作系统 FSKit 提供进程。核心并发、授权、持久化和 FD 生命周期仍以功能测试覆盖，不把功能测试当性能样本。
