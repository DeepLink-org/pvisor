# 宿主 Overlay 请求结果复用的性能对照

路径查找和无句柄属性读取的内部耗时显著下降；写打开和大多数创建操作没有检出稳定改善。这个结论适用于宿主适配器内部路径，真实 FSKit 挂载耗时仍未验证。

## 实验设计

基准编号 **B-FS-ENG**，角色为工程 A/B。对照只包含三项生产修改：创建后复用 metadata、合并物理 metadata 与已复制硬链接查询、写 OPEN 复用 copy-up 结果。其他 stage、lower、日志和 copy-up 优化在两组中保持一致；不能把此前的优化收益归入本报告。

同机 Apple M4（Mac16,12，10 个逻辑 CPU，24 GiB 内存），macOS Darwin 27.0.0 / ARM64，APFS。两组使用独立构建目录和同一 Rust 工具链，按产品 release 配置构建：宿主适配器 opt-level=z、OverlayCore opt-level=3、thin LTO。无 CPU 亲和性或内存配额。

每种配置各做 3 轮预热和 30 轮随机配对，随机种子 20261020；合计 120 个正式运行和 12 个预热运行。每次新建 owner、upper、work 和日志；输入为宿主热缓存中的 768 个 4 KiB 文件。查找和属性读取各 512 次，一半路径位于六级目录；其余每项各 128 次。两种配置独立统计，不比较配置之间的速度。

测量方式是在两份冻结源码中插入相同的测试专用 probe 和 fuser ReplySender 导出，产品工作树不增加测试入口或公开接口。查找调用实际的 inode_for_path_with_metadata，属性读取调用 inode_metadata，写打开调用 open_inode_with_backing；mkdir、mknod/FIFO、symlink 调用实际回调，回复经过序列化后只检查成功。Rust Instant 只计各操作循环，排除初始化、进程启动、退出和最终验证。

写阶段包含打开、写 8 字节和关闭；没有显式 upper fsync。compact 配置保留预映像持久化要求。此直接调用路径没有宿主调度队列、异步 prepared-copy preparation 或已有打开句柄，因此不能替代完整写 OPEN 请求、硬链接或句柄重绑定场景的性能结论。

所有运行校验 768 个 lower 文件的字节与身份清单未变，upper 的完整写入字节、目录/FIFO/符号链接类型和链接目标正确，256 个写路径的 compact 观察存在，回复成功且 work 已清空。预热、正式和独立 profile 均无校验失败；没有剔除有效慢值。采样前后检查构建/测试进程，未检出干扰；该边界检查不能排除短暂或其他后台负载。

统计采用中位数及 5,000 次按轮配对 bootstrap 的 95% 区间。14 个区间未作多重比较校正；区间包含 0 的项标为“未检出差异”。按仓库预先规定的分簇规则，28 组分布均未检出分离簇；这不证明没有调度或存储噪声。

## 数据与分析

以下耗时均为每批操作的中位数，单位 ms；每格 n=30。“变化”为优化后相对优化前的耗时变化，负值表示耗时下降。

### 不可变 lower，无日志

| 操作 | 每批次数 | 优化前 ms | 优化后 ms | 耗时变化及 95% CI | 判断 |
|---|---:|---:|---:|---|---|
| 路径查找 | 512 | 12.670 | 9.217 | -27.3% [-44.2%, -12.4%] | 下降 |
| 无句柄属性读取 | 512 | 9.119 | 4.951 | -45.7% [-57.5%, -32.2%] | 下降 |
| 追加打开、写入、关闭 | 128 | 42.913 | 39.022 | -9.1% [-21.6%, +15.1%] | 未检出差异 |
| 截断打开、写入、关闭 | 128 | 32.081 | 31.670 | -1.3% [-7.5%, +7.1%] | 未检出差异 |
| 创建目录 | 128 | 11.220 | 11.369 | +1.3% [-6.1%, +7.0%] | 未检出差异 |
| 创建 FIFO | 128 | 9.520 | 8.577 | -9.9% [-17.3%, -4.1%] | 下降 |
| 创建符号链接 | 128 | 10.280 | 9.311 | -9.4% [-18.7%, +2.0%] | 未检出差异 |

### 可变 lower，compact 日志

|---|---:|---:|---:|---|---|

| 无句柄属性读取 | 512 | 17.610 | 9.132 | -48.1% [-52.9%, -39.4%] | 下降 |
| 追加打开、写入、关闭 | 128 | 203.766 | 204.999 | +0.6% [-2.4%, +10.6%] | 未检出差异 |

查找耗时在两种配置下分别下降 27.3% 和 50.0%，属性读取分别下降 45.7% 和 48.1%。这与删除重复解析的目标一致。无日志 FIFO 创建检出 9.9% 的下降，但它是多项未校正比较中的单项结果，不据此概括所有创建操作。

追加和截断写打开均未检出稳定改善，不能宣称写入性能已经提高。创建目录、符号链接和 compact 下的 FIFO 也未检出稳定变化。调用次数减少与整段耗时改善是不同结论，复制、元数据保存和日志持久化等工作仍然存在。

慢样本全部保留。例如 compact 追加写的描述性 P95 从 303.01 ms 变为 420.49 ms，截断写从 300.30 ms 变为 523.24 ms；只有 30 个样本，不据此判断稳定尾延迟回归，也不把中位数不显著解释成“没有回归”。未报告 P99。

另跑四个 profile 运行，每种配置、每个版本各一个；这些耗时不进入上表。所有注册的 profile 实例均有 final 记录，两种配置的计数一致。以下计数覆盖全部七个阶段及公共准备步骤，不能当作单个请求的系统调用次数。

### 覆盖范围与失败记录

真实 FSKit 挂载预检在首个计时样本之前阻塞，有效样本为 0；其结果没有混入内部路径统计。非阻塞 MNT_NOWAIT 查询未发现该私有挂载。终止信号已发给基准协调器和自行启动的探测进程，但部分进程处于系统 I/O 等待。自动审批拒绝终止系统 FSKit 提供进程，因为无法证明它仅服务于本基准，可能影响其他挂载；未继续执行该动作。

未测真实 FUSE/FSKit 传输、Linux、VM、冷磁盘、并发吞吐、READDIRPLUS 的独立耗时、prepared-copy 完整请求、整段 Agent 任务与稳定尾延迟。已有功能测试覆盖硬链接、句柄重绑定和符号链接拒绝，但本报告不把这些测试当作性能样本。
